# 会话中文摘要验证记录

## 功能

新会话首次成功完成一轮后，CLI 使用该轮模型后台生成一次中文标题。标题依据用户请求和该轮最终结果，与真实 thread_id 分开保存；`/resume` 和底栏优先显示摘要，没有摘要时显示 thread_id。历史会话不自动补全，后续回合不自动改写。

标题请求使用独立客户端、空的图上下文和无工具的非流式调用，不写入对话 checkpoint 或主任务的性能历史。调用前过滤已知配置密钥及路径、令牌等模式，保存前校验长度、格式和敏感内容。超时、取消和无效输出回退为 ID。

## 重点场景

- 数据库补齐可选摘要列后，会话目录、排序时间和已有 checkpoint 保留；摘要写入采用按 ID 的空值条件更新，重启后可读取。
- 首个成功回合仅请求一次标题；历史会话不触发；排队回合不覆盖首轮请求或结果。
- Responses 和 Chat Completions 通过实际 SDK 的内存传输验证标题载荷、非流式请求、单次调用及客户端关闭。
- 后台结果按捕获的 thread_id 保存；切换会话或推进 UI 运行代号后，晚到的标题仍绑定原会话。
- 超时、异常、退出取消、无 UI 事件循环及非法标题均不改变主任务状态；没有有效标题时显示 ID。
- 同名摘要保持不同的选择值；显示重绘使用缓存，不逐帧读取数据库。
